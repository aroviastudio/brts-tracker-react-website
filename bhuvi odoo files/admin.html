🔑 Google Firebase Cloud Credentials

Paste your free Firebase project settings here. This allows client bookings to reach you and ensures your gallery updates are visible to visitors worldwide.

📖 2-Minute Guide: Getting Free Cloud Database Credentials

Google Firebase provides a 100% free forever tier (50,000 reads/day, 20,000 writes/day, zero credit card needed).

1
Create Free Project: Go to console.firebase.google.com, log in with Google, and click "Add project" (name it e.g. bhuvi-mehandi).
2
Enable Firestore Database: Click "Firestore Database" in the left menu → Click "Create database" → Select "Start in test mode" (or paste the security rules below) → Choose your closest region (e.g. asia-south1 for Mumbai/India).
3
Copy Config: Click the Gear icon ⚙️ (Project Settings) → Scroll down to "Your apps" → Click the Web (</>) icon → Copy the firebaseConfig values into the fields above and click "Save & Connect"!
🔒 Recommended Firestore Security Rules:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
