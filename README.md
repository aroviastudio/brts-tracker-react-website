# AI WhatsApp Chatbot Demo 💬

A high-performance, client-tailored 24/7 AI WhatsApp Chatbot demo platform built with React 19, Google Gemini AI (`gemini-3-flash-preview`), and interactive WebGL `<MicroSlats />` background.

## 🌟 Key Features
- **Client-Specific Personalized Demos**: Dedicated demo URLs (`?b=<lead_id>`) for individual businesses with complete data isolation (no switcher visible to clients).
- **Google Gemini AI Backend**: Powered by Google Gemini (`models/gemini-3-flash-preview`) with verified fallback registry data.
- **Realistic WhatsApp Business Interactions**: Built with interactions supported by the WhatsApp Business API (interactive action chips, markdown formatting, direct call links).
- **Interactive WebGL MicroSlats**: Fluid responsive background with touch and cursor reactivity.
- **Admin Switcher**: Switch effortlessly between client demos by appending `&admin=true` to any URL.

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
